---
description: Messaging on WhatsApp Web — draft only, never send.
name: web-whatsapp
url_pattern: ^https://web\.whatsapp\.com
---

NEVER send messages — only draft them.

* Type the message in the input field. That is enough; do NOT press Enter or click the Send button.
* `Enter` sends the message immediately — do NOT press Enter alone.
* `Shift+Enter` (or `\n`) inserts a new line — use this if the draft needs multiple lines.
* Do NOT click the send (arrow) button.
* Once the text is typed in the field, stop. The user will review and send manually.
