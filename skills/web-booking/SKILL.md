Use the bookmark/save (heart icon) when planning or browsing hotels. Click the heart and ensure the icon changes (e.g. filled/red).

Create a new list named with date and location, e.g. `Paris 08-08-2026`. If a list with that name already exists, add an extra identifier to distinguish it.

If the user is not logged in, ask whether they want to log in first. If they decline, keep tabs open instead and let them know.
